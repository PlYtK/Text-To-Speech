# Twitch Text-To-Speech

<div align="right">
  <a href="README.md">English</a> | <strong>Русский</strong>
</div>

Минималистичное десктопное приложение в пиксельном стиле для озвучивания сообщений из чата Twitch с помощью голосового движка Windows SAPI5. Обладает глубокой темной темой, контрастной пиксельной типографикой и динамической адаптацией под системный акцентный цвет Windows.

## Особенности
- **Пиксельный интерфейс (Pixel UI)**: Кастомное безрамочное окно с интерактивным бейджем статуса `( ● ) LIVE` / `( ○ ) OFFLINE` и шрифтом `Monocraft`.
- **Дашборд (Split View)**: Панель настроек и живой поток чата отображаются бок о бок на одном экране без всплывающих окон.
- **Управление голосом и громкостью**: Выбор установленных голосов Windows SAPI5, слайдер громкости и кнопка быстрого теста `[ ТЕСТ ЗВУКА ]`.
- **Адаптация под систему**: Автоматически наследует системный акцентный цвет Windows (через реестр DWM) и системный язык интерфейса (`SYSTEM`, `RU`, `EN`).
- **Быстрая навигация**: Плавное переключение между вкладками `[ ЛОГ ]`, `[ ЧЁРНЫЙ СПИСОК ]` и `[ НАГРАДЫ ]`.
- **Чёрный список пользователей**: Фильтрация нежелательных пользователей с возможностью быстрого добавления и удаления по кнопке или клавише `Delete`.

## Стек технологий
- Python 3
- PyQt5
- TwitchIO
- pywin32 (Windows SAPI5)

## Системные требования
- Windows 10 / 11 (64-бит)
- OAuth-токен Twitch (`oauth:xxxxxx`) и имя канала

## Запуск из исходников
```bash
pip install -r requirements.txt
python app.py
```

## Сборка автономного файла (.exe)
Для компиляции в единый переносимый файл `.exe` через PyInstaller:

```bash
pip install pyinstaller
pyinstaller TwitchTTS.spec
```
Или просто запустите файл **`build.bat`** двойным кликом на Windows.  
Скомпилированный файл появится в папке `dist/`: `dist/TwitchTTS.exe`.

## Настройки
Все настройки автоматически сохраняются в файл `settings.json` рядом с исполняемым файлом (канал, выбранный голос, громкость, чёрный список, язык интерфейса и, при включенном сохранении, OAuth-токен).
